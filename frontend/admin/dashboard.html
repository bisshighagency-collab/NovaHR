About this build

The AI Assistant and AI Interview features use a transparent, dependency-free keyword-matching engine. so the whole system runs standalone with no external API key. Swap in a real LLM API later without touching any other part of the app. Attendance is signed on the paper sheet: record late and absent days on the Attendance page; each employee's service and break times (shown under their dashboard clock) are set on the Employees page.
